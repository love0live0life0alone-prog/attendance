# تطبيق سجل الحضور — نسخة PWA

## المحتويات
- `index.html` — التطبيق نفسه
- `manifest.json` — بيانات تعريف الـ PWA (الاسم، الأيقونات، وضع standalone)
- `service-worker.js` — يخزن الملفات مؤقتًا عشان التطبيق يشتغل حتى بدون نت
- `icons/` — أيقونات التطبيق (192px و512px)

## رفع المشروع على GitHub Pages

1. اعمل Repository جديد على GitHub وارفع الملفات دي كلها زي ما هي (من غير تغيير في أسماء الفولدرات).
2. من إعدادات الـ Repo: **Settings → Pages**
3. اختار **Deploy from a branch** → الفرع `main` والفولدر `/ (root)`
4. بعد شوية هيديك رابط شبيه بـ:
   `https://username.github.io/repo-name/`
5. افتح الرابط من موبايل أندرويد (Chrome) هيظهرلك اقتراح "إضافة للشاشة الرئيسية" تلقائيًا، أو من القائمة ⋮ اختار **Add to Home screen**.
6. **مهم لأجهزة آيفون:** الـ PWA على iOS محتاج المستخدم يعمل الخطوة يدويًا: يفتح الرابط في Safari → زر المشاركة (Share) → **إضافة إلى الشاشة الرئيسية**. آيفون مبيدّيش اقتراح تلقائي زي أندرويد، لازم توضح الخطوة دي لعملائك.

## عن إخفاء علامة "متصفح"
- لما يفتح التطبيق من أيقونة الشاشة الرئيسية (مش من المتصفح)، هيشتغل في وضع `standalone`: من غير شريط عنوان ولا أزرار المتصفح — يظهر كتطبيق حقيقي.
- تم تعطيل حركة "اسحب للتحديث" (Pull-to-Refresh) بحيث السحب لأسفل مبيعملش Reload للصفحة.
- الأيقونة والاسم اللي هيظهروا على الشاشة الرئيسية جايين من `manifest.json` — تقدر تغيّرهم من هناك وقتما تحب.

## ملاحظة
النسخة دي لسه Local Storage (بيانات كل جهاز عنده لوحده). لو عايز تحويلها لنظام فيه سيرفر وقاعدة بيانات حقيقية ومصادقة (زي ما اتكلمنا قبل كده)، ده مشروع تاني محتاج Backend منفصل.
